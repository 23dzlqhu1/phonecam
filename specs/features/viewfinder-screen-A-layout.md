# Viewfinder 屏布局设计 (A 阶段)

> 🎨 **本文档作用**：PhoneCam viewfinder（取景器）屏的**布局**设计稿。
> 不含视觉风格（颜色/字体/间距）——那是 C 阶段的事。
> 不含多屏导航——那是 B 阶段的事。
> **当前状态**：A 阶段，待用户确认。

---

## 1. 选型记录

| 决定 | 选项 | 原因 |
|------|------|------|
| 设计范围 | D. A → C → B 顺序 | 先做手头的，再扩展 |
| viewfinder 元素 | 5 个全选 | 用户明确需要 推流/连接状态/设置/调试/切换摄像头 |
| 布局风格 | A. 垂直堆叠四层 | 像 DJI Osmo Pocket / 手机原生相机，专业且易理解 |
| 相机画面占比 | 适中型 (40-50%) | 平衡画面与控件 |
| 推流指示 | 按钮上方蓝点闪烁 (1Hz) | 远距离也能看出是否在推 |
| 异常样式 | 图标 + 文字 | 信息量足，新手友好 |

---

## 2. 四层结构 (Vertical Stack)

```
┌──────────────────────────────────────────────────┐  ── 屏幕顶部
│ Layer A: 相机画面                                 │
│   - TextureView，顶对齐 FIT (16:9 → 满宽)         │
│   - weight=4，约占 40-50% 高度                    │
│                                                    │
│                                                    │
│                                                    │
│                                                    │
│                                                    │
├──────────────────────────────────────────────────┤  ← 分隔线 (细)
│ Layer B: 状态 + 设置行                             │
│   - 高度 ~80dp                                     │
│   - 左 33%: ● PC 连接状态 (圆点 + IP 或"未连接")   │
│   - 中 34%: 实时调试 (分辨率 · fps · 码率)          │
│   - 右 33%: ⚙ 设置  🔄 切换前后摄像头 (两个图标)   │
├──────────────────────────────────────────────────┤
│ Layer C: 大推流按钮                                │
│   - 高度 ~120dp                                    │
│   - 居中, 圆角矩形 (或椭圆), 宽 60% 屏宽           │
│   - 未推流: 灰底白字 "▶ 开始推流"                   │
│   - 推流中: 红底白字 "■ 停止推流"                   │
├──────────────────────────────────────────────────┤
│ Layer D: 底部状态文字                              │
│   - 高度 ~40dp                                     │
│   - 居中, 小灰字                                    │
│   - 内容: "PhoneCam v0.2.3 · 相机 0 · 00:01:23"   │
└──────────────────────────────────────────────────┘  ── 屏幕底部
```

### 2.1 Layer A — 相机画面
- **位置**：屏幕顶部，紧贴状态栏下方
- **尺寸**：weight=4（占可用高度 40-50%）
- **比例**：FIT（保持相机原生宽高比，不变形）
- **背景**：黑（letterbox 部分填黑）
- **现状**：✅ 已实现（v0.2.3-mvp2-batch3-topfit）

### 2.2 Layer B — 状态 + 设置行
- **位置**：相机画面正下方
- **高度**：固定 80dp
- **布局**：水平 LinearLayout，3 段等宽

| 区域 | 内容 | 颜色（C 阶段定） |
|------|------|------|
| 左 33% | `●` 圆点 + "已连接 192.168.1.10" 或 `○` "未连接" | 绿/灰 |
| 中 33% | "1280×720 · 30 fps · 0 kbps" | 白/灰 |
| 右 33% | ⚙ 设置  +  🔄 切换摄像头  (两个 ImageButton) | 白图标 |

- **行为**：
  - 点击 `⚙` → 跳转到"设置"页（B 阶段详设）
  - 点击 `🔄` → 切换前后摄像头
  - 长按 `●/○` 区域 → 弹出"扫码连接 PC"对话框（B 阶段详设）

### 2.3 Layer C — 大推流按钮
- **位置**：状态栏下方，居中
- **高度**：固定 120dp
- **宽度**：60% 屏宽（约 760px @ 1272px 屏）
- **形状**：圆角矩形（radius=24dp）或椭圆
- **状态机**：

| 状态 | 文案 | 背景 | 文字 | 可点击 |
|------|------|------|------|--------|
| 推流关闭 | "▶ 开始推流" | 灰 | 白 | ✅ |
| 推流中 | "■ 停止推流" | 红 | 白 | ✅ |
| 推流中但 PC 断连 | "推流中断" | 橙 | 白 | ✅ |
| 摄像头未就绪 | "请先打开摄像头" | 深灰 | 灰 | ❌ |

- **交互**：
  - 点击 → 启动/停止推流
  - 启动时：弹 toast "推流中..."
  - 停止时：弹 toast "已停止"

### 2.4 Layer D — 底部状态文字
- **位置**：屏幕底部
- **高度**：固定 40dp
- **内容**：`PhoneCam v{versionName} · 相机 {cameraId} · {运行时间}`
- **例**：`PhoneCam v0.2.3-mvp2-batch3-topfit · 相机 0 · 00:01:23`
- **样式**：12sp，居中，颜色待 C 阶段定

## 3. 验收标准 (Acceptance Criteria)

> 📋 每条 AC 都用 Given-When-Then 格式。后续 TDD 测试直接引用 AC 编号。

### 正常流程

**AC-VF-001** — 顶部相机画面
```
Given 用户已授予 CAMERA 权限且后置摄像头空闲
When App 启动并完成 onCreate
Then 屏幕顶部 40-50% 区域显示真实后置摄像头预览, 顶对齐 FIT
And 预览宽高比与相机原生输出一致 (无拉伸)
And 预览下方 (letterbox 区域) 填黑色
```

**AC-VF-002** — PC 连接状态指示
```
Given 用户未连接 PC
When viewfinder 屏加载完成
Then Layer B 左侧显示 "○ 未连接" (灰色圆点 + 灰色文字)
When 用户成功连接到 PC
Then Layer B 左侧显示 "● 已连接 192.168.1.10" (绿色圆点 + 白色文字)
```

**AC-VF-003** — 实时调试信息
```
Given 后置摄像头已打开
When 预览稳定运行
Then Layer B 中部显示 "1280×720 · 30 fps · 0 kbps"
And FPS 每秒刷新一次
And 码率仅在推流时 > 0
```

**AC-VF-004** — 设置 + 切换摄像头入口
```
Given 任何 viewfinder 显示状态
When 用户点击 Layer B 右侧 ⚙ 图标
Then 跳转到"设置"屏
When 用户点击 Layer B 右侧 🔄 图标
Then 关闭当前摄像头, 打开另一个摄像头
And 预览画面刷新为新摄像头的内容
```

**AC-VF-005** — 推流按钮状态机
```
Given 当前推流已停止, PC 已连接
When 用户点击 Layer C 按钮
Then 按钮变红色, 文案变 "■ 停止推流"
And toast 弹 "推流中..."
And Layer C 上方出现蓝色脉冲点 (推流指示)
When 用户再次点击按钮
Then 按钮变灰色, 文案变 "▶ 开始推流"
And toast 弹 "已停止"
```

**AC-VF-006** — 底部状态文字
```
Given App 正常运行
When 任何时刻
Then Layer D 显示 "PhoneCam v0.2.3-mvp2-batch3-topfit · 相机 0 · 00:01:23"
And 运行时间每秒刷新一次
```

### 边界 / 异常

**AC-VF-007** — 权限被拒
```
Given 用户在系统权限弹窗中点了"拒绝"
When App 启动完成
Then Layer A 显示占位文字 "请授予摄像头权限" + "重新申请" 按钮
And Layer C 按钮置灰, 不可点击
And Layer B 右侧两个图标仍可点击 (齿轮可调系统设置)
```

**AC-VF-008** — 摄像头被占用
```
Given 另一个 App 正在使用后置摄像头
When App 尝试 openCamera 失败
Then Layer A 显示占位文字 "摄像头被占用, 请关闭其他相机 App"
And 3 秒后自动重试一次
```

**AC-VF-009** — 未连接 PC 启动推流
```
Given 用户未连接 PC
When 用户点击 Layer C 按钮
Then 按钮短暂变橙色 "请先连接 PC", 持续 2 秒
And 2 秒后恢复灰色 "▶ 开始推流"
And 不实际启动推流
```

**AC-VF-010** — 推流中断 (PC 突然掉线)
```
Given 用户正在推流, PC 突然断开
When 推流 socket 报错
Then 按钮变橙色 "推流中断"
And Layer B 左侧变 "○ 未连接"
And 5 秒后自动重连 1 次
```

### 业务规则

**AC-VF-011** — 文字更新频率
```
Given 调试信息运行中
When 1 秒经过
Then FPS 数字至少变化 1 次
And 码率数字根据最近 1 秒实际发送字节数计算
```

**AC-VF-012** — 按钮可点击区域
```
Given Layer C 按钮显示
When 屏幕 1272px 宽
Then 按钮宽度 ≥ 600px (屏宽的 47%)
And 按钮高度 ≥ 80dp
And 点击按钮边缘 10px 内仍可触发
```
