# PhoneCam GUI 设计规范

> 最后更新: 2026-06-11
> 审美方向: 朴素学术风格，内容密度高，无 AI 感

---

## 1. 竞品分析摘要

| 特性 | Iriun Webcam | DroidCam | Camo | EpocCam |
|------|-------------|----------|------|---------|
| **手机端 UI** | 极简：大按钮+预览 | 简洁：IP显示+连接状态 | 精致：设置丰富 | 中等：预览+控制 |
| **桌面端 UI** | 无独立窗口（虚拟摄像头直出）| 小窗口：预览+控制栏 | 独立窗口：预览+丰富设置 | OBS插件/独立窗口 |
| **连接方式** | 自动发现（WiFi/USB）| 手动输入IP | USB优先+WiFi | WiFi/USB |
| **状态指示** | 通知栏+手机端文字 | 桌面端状态栏 | 连接状态徽章 | 状态灯 |
| **视觉风格** | 无装饰，功能优先 | 轻量，原生控件 | 现代，精致 | 流媒体风格 |

**关键发现**:
- Iriun 桌面端**没有独立 GUI**——直接作为虚拟摄像头输出，会议软件直接识别
- DroidCam 桌面端是最小化的——小窗口 + 基本控制
- Camo 设置最丰富但界面复杂
- **用户真正需要的是**：启动→自动连接→看到画面，中间不要有障碍

## 2. 设计原则

```
1. 功能优先，装饰为零
   - 不用渐变、阴影、圆角卡片
   - 用线条和间距分隔区域
   - 颜色只用于状态指示（绿=好，红=坏，黄=警告）

2. 信息密度最大化
   - 每个像素都有用
   - 状态信息一行搞定，不占大块区域
   - 预览画面最大化，控件最小化

3. 学术图表风格
   - 字体：等宽字体（Consolas/Monaco）用于数据，无衬线用于标签
   - 配色：白底黑字 + 蓝色强调（学术蓝 #0066CC）
   - 对齐：严格网格对齐，等间距

4. 零学习成本
   - 启动即用，不需要看说明书
   - 状态一目了然
   - 控件自解释
```

## 3. 桌面端 GUI 布局

```
┌─────────────────────────────────────────────────────┐
│ PhoneCam v0.6.1          ● CONNECTED  1280x720 29fps │  ← 状态栏（单行，等宽）
├─────────────────────────────────────────────────────┤
│                                                     │
│                                                     │
│              [ 摄像头预览画面 ]                        │
│              最大化显示区域                             │
│              黑色背景，原始比例                          │
│                                                     │
│                                                     │
├──────────┬──────────┬──────────┬───────────────────┤
│   镜像   │   翻转   │   旋转   │  ▶ 虚拟摄像头      │  ← 控制栏（紧凑，一行）
└──────────┴──────────┴──────────┴───────────────────┘
```

### 状态栏规格
```
位置: 顶部，高度 28px
背景: #F5F5F5（浅灰）
分隔: 底部 1px solid #DDD

内容（从左到右，用 │ 分隔）:
  PhoneCam v{version}          ← 产品名+版本号
  ● {state}                    ← 状态灯 + 状态文字（绿/红/黄）
  {resolution}                 ← 如 1280x720
  {fps}fps                     ← 如 29fps
  ▲{bytes_sent}KB              ← 已发送数据量
```

### 预览区规格
```
位置: 状态栏下方，占满剩余空间
背景: #000000（纯黑）
内容: 摄像头画面，保持原始宽高比，居中显示
旋转: 支持 0/90/180/270
镜像/翻转: 支持
```

### 控制栏规格
```
位置: 底部，高度 36px
背景: #F5F5F5
分隔: 顶部 1px solid #DDD

按钮样式:
  - 无圆角，直角矩形
  - 背景 #FFFFFF，hover #E8E8E8
  - 边框 1px solid #CCC
  - 字体 12px 无衬线
  - 间距 4px

按钮:
  [镜像] [翻转] [旋转 0°] │ [▶ 虚拟摄像头]
  - 镜像/翻转: 切换按钮，激活时背景 #E0E0FF
  - 旋转: 点击循环 0°→90°→180°→270°
  - 虚拟摄像头: 开/关切换，激活时背景 #E0FFE0
```

│ PhoneCam          ⚙        │  ← 标题栏（36px）
├─────────────────────────────┤
│                             │
│                             │
│   [ 摄像头预览 ]              │  ← 全屏预览
│                             │

### 手机端设计原则
- 预览最大化（占 70%+ 屏幕面积）
- 状态条用等宽字体，信息密度高
- 按钮大但不花哨
- 连接信息始终可见

## 5. 状态机与用户反馈

```
状态流转:
  IDLE → CONNECTING → CONNECTED → STREAMING
         ↓ 失败
       ERROR → IDLE（自动重试）

状态灯:
  IDLE       ● 灰色   "空闲"
  CONNECTING ● 黄色   "连接中..."
  CONNECTED  ● 绿色   "已连接"
  STREAMING  ● 蓝色   "推流中 29fps"
  ERROR      ● 红色   "错误: {原因}"

自动行为:
  - 启动时自动搜索设备（USB > WiFi）
  - 找到设备自动连接
  - 连接成功自动开始推流
  - 断开自动重连（指数退避）
```

## 6. 配色方案

```
背景色:
  主背景:   #FFFFFF（纯白）
  次背景:   #F5F5F5（浅灰，状态栏/控制栏）
  预览背景: #000000（纯黑）

文字色:
  主文字:   #1A1A1A（近黑）
  次文字:   #666666（中灰）
  数据文字: #333333（深灰，等宽字体）

强调色:
  学术蓝:   #0066CC（链接、选中状态）
  成功绿:   #008800（连接成功）
  警告黄:   #CC8800（连接中）
  错误红:   #CC0000（错误状态）

边框色:
  分隔线:   #DDDDDD
  按钮边框: #CCCCCC
  焦点边框: #0066CC
```
