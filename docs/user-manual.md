# PhoneCam 使用手册

> 把 Android 手机变成 Windows 电脑的摄像头

---

## 快速开始（3 分钟）

### 第一步：安装手机 App

1. 把 `app-release.apk` 传到手机（微信/QQ/数据线均可）
2. 在手机上打开 APK 文件，允许"安装未知来源应用"
3. 安装完成后打开 **PhoneCam**

### 第二步：安装电脑端

**方式 A：直接运行 EXE（推荐）**

1. 把 `phonecam.exe` 放到电脑任意目录
2. 双击运行

**方式 B：Python 环境运行**

```bash
pip install opencv-python pyvirtualcam numpy Pillow av
python phonecam.py --gui
```

### 第三步：连接

**USB 连接（推荐，最稳定）**

1. 用 USB 数据线连接手机和电脑
2. 手机开启 **USB 调试**（设置 → 开发者选项 → USB 调试）
3. 手机上打开 PhoneCam，点 **开始推流**
4. 电脑上双击 `phonecam.exe`
5. 自动连接，看到画面 ✅

**热点连接（无需数据线）**

1. 手机开启 **个人热点**
2. 电脑连接手机热点
3. 手机上打开 PhoneCam，点 **开始推流**
4. 电脑上双击 `phonecam.exe`
5. 自动连接，看到画面 ✅

### 第四步：在会议软件中使用

1. 安装 [OBS Studio](https://obsproject.com/)（免费，装一次就行）
2. phonecam.exe 启动后会自动创建虚拟摄像头
3. 打开腾讯会议/Zoom/Teams
4. 在摄像头设置中选择 **OBS Virtual Camera**
5. 会议中就能看到手机摄像头画面 ✅

## 常见问题

### Q: USB 连接后没反应？

确保：
- 手机已开启 USB 调试
- 手机上弹出"允许 USB 调试"对话框时点了"允许"
- 数据线支持数据传输（不是只能充电的线）

### Q: 热点连接后没反应？

确保：
- 手机热点已开启
- 电脑已连接手机热点（不是校园网/WiFi）
- 等待 3-5 秒（自动检测需要时间）

### Q: 画面模糊？

- 确保手机摄像头对焦清晰
- 如果用前置摄像头，距离不要太近（广角镜头近距离会畸变）
- 已内置畸变校正，比之前版本有改善

### Q: OBS Virtual Camera 找不到？

- 确保已安装 OBS Studio
- 安装 OBS 后需要重启电脑
- 在 OBS 中：工具 → 虚拟摄像头 → 启动

### Q: 帧率很低？

- USB 模式通常 25-30 FPS
- 热点模式取决于 WiFi 信号质量
- 关闭手机省电模式

## 技术参数

| 参数 | 值 |
|------|-----|
| 分辨率 | 1280x720 (720p) |
| 帧率 | 25-30 FPS |
| 编码 | H.264 (硬件编码) |
| 协议 | PCP v2 (自研) |
| 传输 | TCP (USB/热点) |
| 延迟 | < 100ms |

## 卸载

**手机端：** 设置 → 应用 → PhoneCam → 卸载

**电脑端：** 删除 `phonecam.exe` 即可（绿色软件，无注册表）
