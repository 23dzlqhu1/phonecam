## ✨ 核心特性

- 🎥 **1080p 60fps** 高清画质
- 🔌 **USB / WiFi 热点** 两种连接方式
- 🎤 **音视频同步**（画面 + 麦克风）
- 🛠️ **零配置**：手机 App + 电脑 EXE 一键连接
- 🌐 **自研协议 PCP**：从协议层复刻 Iriun Webcam
