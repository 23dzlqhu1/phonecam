PhoneCam - 手机摄像头虚拟摄像头
====================================

将 Android 手机摄像头变成 PC 端虚拟摄像头，
可在腾讯会议、Zoom、OBS 等任何支持摄像头的软件中使用。

安装步骤
--------

1. 运行 install.bat（需要管理员权限）
   - 自动注册虚拟摄像头 DLL
   - 自动安装 APK 到已连接的手机（需 adb）
   - 创建桌面快捷方式

2. 双击桌面 "PhoneCam" 快捷方式启动 PC 端

3. 在手机上打开 "PhoneCam" App，点击 "开始推流"

4. 在腾讯会议/Zoom/OBS 中选择 "PhoneCam Camera" 作为摄像头
   如果未出现，请重启腾讯会议。

连接方式
--------

USB（推荐，最低延迟）：
  1. 用 USB 数据线连接手机和电脑
  2. 手机上开启 USB 调试（设置 → 开发者选项 → USB 调试）
  3. PC 端 PhoneCam 会自动检测并连接

WiFi / 手机热点：
  1. 手机开启热点，电脑连接手机热点
  2. 或者手机和电脑连接同一 WiFi
  3. PC 端 PhoneCam 会自动搜索手机

遇到问题？
----------

1. 确认手机端 PhoneCam App 已打开并开始推流
2. 确认 PC 端 PhoneCam 已启动
3. 如果用 USB，确认手机上已允许 USB 调试
4. 如果用 WiFi，确认手机和电脑在同一网络
5. 如果腾讯会议中看不到 PhoneCam，重启腾讯会议
6. 日志文件在 logs/ 目录下，可发给开发者排查

卸载
----

运行 uninstall.bat（需要管理员权限）

系统要求
--------

- Windows 10/11 (64-bit)
- Android 7.0+
- USB 数据线（推荐）或同一 WiFi 网络
