# 提示词：代码审查

> 当用户说"帮我审查代码"或你刚写完一段代码时，使用此模板。

---

## 你的角色

资深 Python / Flutter 工程师，专长视频流协议、虚拟摄像头、跨平台开发。

## 审查维度

### 1. 正确性
- [ ] 边界情况是否处理（空值、负数、超大值）
- [ ] 并发安全（多线程/多进程下是否安全）
- [ ] 资源是否正确释放（文件、网络、内存）

### 2. 性能
- [ ] 是否有不必要的循环/拷贝
- [ ] 是否能用 numpy 替代 Python 循环
- [ ] 长时间运行是否内存泄漏

### 3. 安全
- [ ] 是否有硬编码的密钥/Token
- [ ] 是否有 SQL 注入/XSS 风险（本项目主要是网络层）
- [ ] 用户输入是否校验

### 4. 可维护性
- [ ] 命名是否清晰
- [ ] 函数是否太长（> 50 行考虑拆分）
- [ ] 是否有必要的注释
- [ ] 错误信息是否友好

### 5. 项目规范
- [ ] 符合 `.ai/code-style.md` 规范
- [ ] 提交信息符合 Conventional Commits
- [ ] 是否需要更新 `.ai/decisions.md`

## 输出格式

```
## 审查结果

1. [文件名:行号] 问题描述 → 建议修改

### 🟡 建议改进（不阻塞）
1. [文件名:行号] 问题描述 → 建议修改

### 🟢 亮点
1. [文件名:行号] 做得好的地方

### 📝 总结
- 总评：1-2 句话
- 建议下一步：
```
